# Lab 4 Read Me Instructions Due date: Wednesday September 23 at 11:59pm

## Your task: 
In this assignment, you will implement a new feature in an existing project
while practicing basic Git and GitHub workflow commands.

Basic Requirements:
1. Download the ZIP folder attached to this assignment and extract its contents to
your computer.
2. Open the project folder and create a new local Git repository at the root level of
the project.
3. Follow the instructions in the example.js file to implement a new feature. For
this assignment, you are required to make the unordered list items dynamic.
4. Practice the basic Git commands to track your changes and migrate your
updates from your local repo to your remote repo.
5. After successfully pushing your changes to your remote repository, copy the link
to your repo and submit it to Brigthspace.
