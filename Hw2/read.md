## Goal & Due date: Tuesday September 22 at 11:59pm
Your task: Learn how classes and object-oriented programming work in JavaScript,
then apply what you learn by designing and coding your own JavaScript class.

## Requirements: Overview
1. Research. Before starting the coding portion, read about JavaScript classes
using resources, such as MDN Docs, w3schools, or any resources of your
preference. As you read, make sure you understand the following concepts:
class, objects, constructors, properties/fields, private fields using #, instance
methods, the new and this keywords, difference between a class and an
instance/object, getters and setters, and static methods/properties.

2. Design your own class. Choose any topic you are interested in and design a
JavaScript class around it. For example, a class to model a student, bank
account, product, playlist, movie. You are encouraged to choose something
that is original and interesting to you.

3. Basic class requirements:
- a. Constructor
- b. At least one private field
- c. At least three instance methods.
- d. At least one getter and setter
- e. Instantiate at least three different - objects with the new keyword
- f. Call your methods.
- g. Document your code by adding comments, explaining the meaning or
intention of each of the basic class requirements listed between a to f.
Submission: Use the Brightspace submission tools to upload one JavaScript (.js) 
file containing your class, objects, method calls, comments, and the sources you 
used for your research.
